测试材料：

- `refs/imo2022`：第 63 届 IMO 预选题几何，G2–G8，7 题
- `refs/imo2025`：第 66 届 IMO 预选题几何，G1–G7，6 题

## 2. 当前引擎已有、但 vision/construction 语法未完全暴露

这些不是几何内核缺失，而是模型无法稳定输出：

- `reflectLine`、`reflectPoint`、`rotate`、`translate`、`homothety`、`inversion`、`isogonal`
- `tangentAt`（过圆上一点的切线）
- `tangentFrom`（从圆外一点作切线，带分支）
- `radical`（根轴）
- `polar` / `pole` / `harmonic`
- `midpointArc` / `incircleTouch`
- `tangentAtPoint`（过 A、B 且切定线于 A 的圆）
- 圆-圆交点、线-圆交点

## 3. 真正的内核缺口（按优先级）

### P0：约束选择器
需要一个通用的“自由参数 + 约束”求解层：

- 长度等式：`OW=OD`、`BN=EM`、`MG=ME`
- 角等式：`∠AEC=∠OEB`、`∠CAD=∠CBX`
- 共圆/共线/共点/相切约束
- 点在线/圆上的联合约束

目前只有 `angleDouble`、`equalDistance` 两个专用派生点，无法覆盖 G4/G5/1034 等。

### P1：相切圆族
- 圆与两条直线相切（含指定切点/半径）
- 圆与两圆相切（内切/外切分支）
- 圆与直线+圆同时相切
- 两圆公切线、切点、切圆族
- 圆外切四边形的判定与构造

影响：G8、2025 G1/G7、1037、1038。

### P2：轨迹/包络/定点
- 动点参数化
- 线族/圆族包络
- 定点发现（数值+符号）
- 与定圆相切

影响：G6、1040。

### P3：圆锥曲线
- 由中心+过两点/轴确定的椭圆
- 线-椭圆、圆-椭圆交点
- 椭圆上的切线与内切圆联合约束

影响：1031。

### P4：共点/共圆约束构造
- 塞瓦共点选点
- 圆内接六边形+两内切圆切对边
- 固定外接圆+垂心的参数化族

影响：G7、G8、1036。

### P5：非构图题
1033 是映射/函数题，不应强行生成几何图。

## 4. 建议的测试门槛

新增构型必须通过：

1. 拖动自由点后，所有派生点仍满足定义；
2. 条件构型在约束满足时目标残差 < 1e-8；
3. 导出 PNG/PDF 后点顺序与参考图一致；
4. vision construction 与手工 scenario 都能生成同一对象类型；
5. 不能用文字关键词套历史构型。
