## 2. 前 5 题识图抽样

对第 1–5 页做视觉识别，5/5 返回了 construction，但**0/5 能直接保证正确**。

| 题 | 模型给出的构造 | 结论 |
|---|---|---|
| 1 | `onSegment / onCircle / onRay / midpointArc` | `onRay` 当前不支持；∠CAE=∠BAD、AF=AD、CG=BD 均未强制 |
| 2 | 多个 `intersection` + 圆 | 依赖圆-圆/圆-线分支，条件 `onCircle` 未形成约束求解 |
| 3 | 旁心 + 等距 + 反射 | `equalDistance` 只能处理特定 CA 方向；旁心/等距需要通用约束 |
| 4 | 自由点 + 反射 + 等长 | `equalLength` 仅是 constraints 文本，没有自动求解；`sameSide` 不支持 |
| 5 | 反射 + 交点 + 相切 | 两条 `perpendicular` 约束未绑定到可求解参数 |

模型能提出“看起来像”的 construction，但很多关键条件是自然语言约束，不是几何原语。

## 3. 按图片坐标绘制

- 自由点优先使用 construction 的 `at`；缺失时回退到 points 的原图 `coordinate`。
- 交点、`pointOnCircle`、`pointOnRay`、切点优先用原图坐标选择分支/参数。
- 安装后 `fitView`，但 fitView 只保证不超出画布，不保证与参考图逐点重合。

## 3.1 位置错位风险

当前策略：

- 自由点使用模型从原图读取的归一化 `at`；
- 派生点由几何条件计算；
- 交点优先按 `coordinate` 选分支；无坐标时，若两对象共享点，取离共享点较远的另一交点；
- 安装后 `fitView` 自动把图形放进画布。

仍会错位的情况：

1. 模型没有给出 `coordinate`，且两个交点没有共享点；
2. 条件点被模型写成 `onSegment/onRay`，位置是手摆的，不满足题设；
3. 圆弧中点、内外切分支选错；
4. 题干点顺序与图中顺序不一致；
5. 多解构型中模型选了错误分支。

因此“图不错位”不能只靠 `fitView`，必须对每题做坐标/条件校验。

## 4. 直接发现的缺口

- `pointOnRay`：未支持；
- `sameSide`：未支持；
- 一般角度约束：`∠CAE=∠BAD` 没有构造原语；
- 一般等长约束：`AF=AD`、`CG=BD` 没有“沿射线取指定长度”的原语；
- 圆-圆/圆-线分支没有统一按参考坐标选择；
- 旁心+等距、九点圆、根轴、公切线等需要逐题构型；
- 动点/定点 4 题需要轨迹层。

## 5. 结论

100 题当前只能做“抽样识图 + 人工核对”，不能承诺批量正确。  
下一步应先补：

1. `pointOnRayDistance`（沿射线取定长）
2. `angleCopyRay`（复制角，交圆/线）
3. 分支统一由参考坐标决定
4. 约束求解接入 construction
5. 每题导出前做残差与点位校验

在这些完成前，不能说 100 题全部支持。
